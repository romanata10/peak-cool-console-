# Проверка экспериментальной сборки

Браузер или антивирус может предупредить об архиве с малоизвестным плагином, но причина конкретного предупреждения известна только по подробному сообщению защитного ПО. Не отключайте защиту и не делайте исключений ради установки. Если антивирус определил угрозу, не запускайте файл; сохраните название обнаружения и проверьте информацию через производителя антивируса.

Папка `releases/PeakCoolConsoleHelper/` содержит экспериментальный ZIP, отдельную DLL и `SHA256SUMS.txt`. ZIP содержит только `manifest.json`, `README.md`, `icon.png` и `plugins/PeakCoolConsole.dll`. Сборку выполняет GitHub Actions из исходного кода ветки с публичными reference-пакетами Unity и BepInEx; конфигурация доступна в `.github/workflows/build.yml`. Сборка не является проверкой в игре или антивирусной проверкой.

Проверить хеш уже сохранённого файла в PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 'C:\path\to\PeakCoolConsoleHelper-0.8.0.zip'
```

Сравните `Hash` с соответствующей строкой `SHA256SUMS.txt` на GitHub. Совпадение показывает только, что файл совпадает с указанной сборкой, **а не что он безопасен**. При несовпадении не устанавливайте файл. Оба файла получены из одного репозитория, поэтому хеш не защищает от компрометации самого репозитория. Внешние зависимости `BepInExPack PEAK` и `AdvancedConsole` устанавливаются отдельно и не проверены этим проектом.

Мод запускает код внутри игры, работает с игровым состоянием и обращается к загруженному AdvancedConsole с помощью рефлексии. Неизвестный код плагина может быть опасен, как и любая другая программа. Исходники мода находятся в `src/`, но самостоятельно изученный исходный код, успешная сборка и наличие хеша не заменяют независимой проверки полученной DLL и зависимостей. Проект не прошёл аудит или антивирусную проверку.
