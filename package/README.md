# Peak Cool Console Helper (прототип)

Небольшой BepInEx-плагин для PEAK, дополняющий [AdvancedConsole 1.1.9](https://thunderstore.io/c/peak/p/keklick1337/AdvancedConsole/). **Это не реализация всех запрошенных команд**: здесь есть экспериментальные локальные полёт, скорость, пауза и туман, кнопки для некоторых команд AdvancedConsole и справочник. Сетевая синхронизация, обход прав хоста и управление чужими клиентами этим плагином не реализованы. Проект не проверен в игре и пока не опубликован на Thunderstore.

## Использование

- Меню пробует открыться при запуске; `F8` или `F10` открывает/закрывает его повторно. Версия 0.7.0 поддерживает новый и старый ввод Unity, разблокирует курсор, пока меню открыто, и пишет сообщение при загрузке в `BepInEx/LogOutput.log`. Окно прокручивается и помещается на небольшом экране.
- `Start flight` — экспериментальный локальный полёт; закройте окно F8 и используйте WASD, пробел вверх, левый Ctrl вниз. `Stop flight` возвращает сохранённую гравитацию. Полёт зависит от внутреннего устройства персонажа и может перестать работать после обновления игры; защита от урона при падении не реализована. Начинайте низко над землёй.
- `Apply speed` / `Restore speed` — установить / вернуть прежний множитель скорости локального персонажа. Игра или другие моды могут его изменить.
- `Pause local game` / `Resume local game` — поставить локальный `Time.timeScale` на 0 / вернуть прежнее значение. Пауза не останавливает других игроков и может нарушать сетевую игру.
- Ползунок и `Apply local fog` — включить локальный туман; `Restore local fog` возвращает предыдущее состояние. Результат зависит от режима тумана текущей сцены. На других игроков это не распространяется.
- Кнопки действий вызывают методы AdvancedConsole напрямую через рефлексию: укажите точный ник и нажмите `Drop coconuts` (1–100, по одному вызову каждые 0,2 секунды; `Stop coconuts` отменяет очередь), `Banana slip`. `Bees near self` создаёт пчёл рядом с собой, а не на указанном игроке. Кнопка `Scoutmaster -> player` вызывает задокументированную команду AdvancedConsole для охоты на игрока; `Stop Scoutmaster` останавливает её, а `Spawn Scoutmaster (host)` пытается создать скаут-мастера (нужен хост). Эти кнопки также не проверены в игре. Кнопки сна/пробуждения игрока или всех отправляют встроенные Photon RPC игры напрямую, без AdvancedConsole на стороне получателей; фактическое действие и права без хоста не проверены. Также доступны извержение на игроке, телепортации, победа, переход на вершину, переход всех на пляж и ускорение игрока (два последних — хост), спавн предмета по названию/ID. Эти действия не переопределяют сетевые ограничения игры. Кнопка вызывает соответствующий метод, но не может гарантировать, что команда действительно сработала или что другие увидят результат; проверяйте игру и журнал консоли. При изменении API AdvancedConsole в окне появится ошибка.
- Кнопка `Copy` копирует пример команды **AdvancedConsole** в буфер обмена. Откройте `F1`, вставьте команду, замените `playerName`, `itemNameOrID` или `searchTerm` на реальные значения и выполните. Эта кнопка только копирует текст; кнопки действий выше пытаются вызывать команды напрямую.

Команды взяты из документации AdvancedConsole 1.1.9; их работа и сетевая видимость зависят от версии игры, ограничений Photon, прав хоста и самой AdvancedConsole. Примеры с пометкой host требуют Master Client. Не предполагается, что все игроки увидят любые изменения, особенно если автор команды не хост.

## Что не реализовано

Спавн всех мобов и предметов без прав хоста, гарантированный вызов скаут-мастера без хоста, динамит в заданном количестве, медузы под игроками, зелёный эффект и звук пука, сетевой туман, текст на экране и произвольные звуки у всех игроков. Справочник содержит отдельные похожие команды AdvancedConsole (например, повторный вызов сброса кокоса, эффект скольжения, сон игроков, победа и переход на вершину), но они не заменяют все функции из запроса. Клиентский мод не может гарантировать сетевое действие на любом сервере: это зависит от сетевой модели игры, разрешений и наличия совместимого кода у участников. Используйте моды и пранки с согласия игроков.

## Сборка и пакет Thunderstore

Нужны .NET SDK, Python 3 и установленная **Mono**-версия PEAK с BepInEx 5.4.2403. Проект ссылается на локальные библиотеки игры и BepInEx, которые не входят в репозиторий. Проверьте `PEAK_Data/Managed/UnityEngine.CoreModule.dll` в каталоге игры. Если BepInEx установлен менеджером, `BepInEx.dll` находится в папке `BepInEx/core` профиля, а не в папке игры. Имя каталога данных в другой версии игры может отличаться.

На Linux/macOS или в Git Bash:

```sh
./build-package.sh '/path/to/PEAK' '/path/to/profile/BepInEx/core'
```

На Windows в PowerShell:

```powershell
./build-package.ps1 -PeakDir 'C:\path\to\PEAK' -BepInExCore 'C:\path\to\profile\BepInEx\core'
```

Вместо примеров путей укажите реальные пути к игре и папке профиля. Если BepInEx установлен прямо в папке игры, `-BepInExCore` можно не указывать. В скрипте для Linux второй аргумент можно пропустить, если BepInEx находится в каталоге игры.

Архив содержит `manifest.json`, `README.md`, `icon.png` и DLL в `plugins/`; его можно загрузить как пакет Thunderstore после проверки в игре. Для ручной установки поместите DLL в `BepInEx/plugins/` и установите AdvancedConsole с её зависимостями. Экспериментальная сборка, если CI завершился успешно, находится в `releases/PeakCoolConsoleHelper/`. Она собрана по публичным reference-библиотекам Unity и BepInEx, а не по библиотекам конкретной установленной игры, и не проверена в PEAK. При несовместимости соберите с файлами своей игры по инструкции выше. Перед публикацией проверьте совместимость с текущими версиями PEAK и зависимостей, содержимое архива и поведение в приватной игре.

## Как установить и опубликовать через Thunderstore

Сейчас нашего мода **нет в каталоге Thunderstore**. ZIP из `releases/PeakCoolConsoleHelper/` — экспериментальный: проверьте его в игре или соберите по инструкции выше. Затем:

1. Установите Thunderstore Mod Manager или совместимый r2modman, найдите PEAK, выберите игру и создайте профиль.
2. В разделе Online установите `BepInExPack PEAK` и `AdvancedConsole` (у AdvancedConsole BepInEx указан как зависимость).
3. Для локального теста импортируйте собранный ZIP через настройки профиля и пункт импорта локального мода, если он есть в вашей версии менеджера. Либо распакуйте **только DLL** в папку `BepInEx/plugins` профиля, найденную через настройки менеджера. Не распаковывайте DLL в обычную папку PEAK, если запускаете модифицированную игру из отдельного профиля.
4. Запустите игру кнопкой `Start modded`, зайдите в приватную игру с согласия друга, нажмите F8 или F10. Сначала проверьте одиночный кокос и полёт рядом с землёй. Сообщение о вызове команды не является подтверждением сетевого эффекта.
5. Чтобы другие могли скачать мод из каталога, войдите на сайт Thunderstore, создайте команду/namespace и загрузите собранный ZIP через страницу загрузки пакета, выбрав сообщество PEAK. Проверьте имя, описание, зависимости и результаты проверки пакета перед публикацией. Когда публикация будет завершена, другие смогут найти пакет по имени и нажать Install в менеджере. Здесь публикация не выполнялась.

Если игра не запускается или F8 не открывается, проверьте актуальность версий PEAK и BepInEx, запустили ли вы именно модифицированный профиль, и журнал `BepInEx/LogOutput.log` в папке профиля. При ошибках `Command signature unavailable` или `Command class not found` кнопки несовместимы с загруженной версией AdvancedConsole; попробуйте оригинальные команды в F1. Не рассчитывайте на эффект для других игроков до отдельной проверки клиентом и хостом.

Методы AdvancedConsole проверены по публичным объявлениям версии 1.1.9: для аргументов Photon выбирается игрок с точным ником; при совпадении нескольких ников действие отменяется. Это не подтверждает сетевое поведение.

Тест упаковщика (без игры и без создания настоящей DLL): `python3 -m unittest discover -s tests`.

### Если F8 не открывает меню

Обновите мод до 0.7.0, удалите старую копию из профиля, запустите игру через `Start modded`, попробуйте F8 и F10. В Thunderstore выберите настройки профиля и откройте папку профиля; в `BepInEx/LogOutput.log` найдите `Peak Cool Console Helper 0.7.0 loaded`. Если её нет или есть ошибки загрузки DLL, приложите файл журнала, предварительно удалив личную информацию. F1 должен открывать AdvancedConsole, если она установлена и загрузилась. Новый ввод — возможная причина проблемы, но без журнала это не доказано.

Для встроенных RPC сна использованы названия методов, также применяемые проектом [PeakMod](https://github.com/TheLocalAdmin/PeakMod). Отправка вызова не подтверждает, что его приняли другие клиенты; некоторые действия могут требовать хоста. Остальные кнопки по-прежнему зависят от AdvancedConsole.
